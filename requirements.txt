# Save-Sale - Requisitos y configuración del proyecto
# Supermercado multiplataforma con Avalonia UI, C# y SQLite

# ==========================================
# INSTRUCCIONES PARA INICIAR
# ==========================================

# Para iniciar el proyecto (hace restore + build + run):
dotnet run --project src/SS/SS.csproj

# O pasos separados si es necesario:
# dotnet run                                          # Compila y ejecuta (recomendado)
# dotnet build                                        # Solo compila
# dotnet new sln add src/SS/SS.csproj                 # Agregar solución (una vez)

# ==========================================
# PAQUETES NÚCLEO INSTALADOS
# ==========================================

# Avalonia UI - Framework multiplataforma (Windows, macOS, Linux, Android)
# - Version: 12.1.1
# - Paquetes: Avalonia, Avalonia.Desktop, Avalonia.Themes.Fluent, Avalonia.Fonts.Inter

# SQLite - Base de datos local embebida
# - Version: 8.0.0 (Microsoft.Data.Sqlite)
# - Sin configuración extra de servidores ni MySQL
# - .db creado automáticamente en primer arranque

# MVVM - Patrón de arquitectura
# - Version: 8.4.2 (CommunityToolkit.Mvvm)
# - ObservableObject, RelayCommand, etc.

# ==========================================
# PAQUETES ADICIONALES (opcionales)
# ==========================================

# ZXing.Net.Mobile - Lectura de códigos QR y de barras
# - Agregado: dotnet add src/SS/SS.csproj package ZXing.Net.Mobile
# - Version: 2.4.1
# - Servicios: Services/QrScannerService.cs creado
# - ViewModel: MainViewModel con ScanQrCommand listo
# - UI: MainWindow.axaml con botón y display de código
# - NOTA: Requiere instalación de workload Android para Android: dotnet workload install android

# ==========================================
# CARGA DE TRABAJO ANDROID (si se quiere compilar para móvil)
# ==========================================

# Para compilar en Android, descomentar TargetFrameworks en SS.csproj:
# <TargetFrameworks>net10.0;net10.0-android</TargetFrameworks>
# <PackageReference Include="Avalonia.Android" Version="12.1.1" />

# Luego instalar:
# dotnet workload install android
